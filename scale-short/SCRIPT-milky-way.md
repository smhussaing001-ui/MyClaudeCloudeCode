# Milky Way — script

Format: 9:16, 30 fps, 1080x1920. Red accent (#ED4839). Same system as STYLE-SPEC.md:
no cuts, vertical slides, long holds, scarce accent.

Structure: 16 scenes, 5 s each, 72.5 s total. Light and dark alternate; the light beats
are breathing room between figures, which is how the reference paces itself.
The arc is one continuous outward journey, then a turn: we are not still, and we are
not alone. Every figure is checked below.

rather than settled numbers. The narration hedges the star count out loud
("nobody has counted them") rather than stating it flat.
